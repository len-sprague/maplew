Column roles
Retag columns and hide fields in the record window. Prefixes on export follow the role you set.
    Location columnsStep 1
    Turn on when the background is a web-map screenshot (Google/OSM/Leaflet, EPSG:3857) and columns are lat/lon. Leave off for plain plots, equirectangular maps, or small extents (≲3° latitude). See design doc §4.
    Background map
    Each PNG can ship with a .calib.txt sidecar (from make-basemap.py). Switch maps to compare layouts — calibration updates automatically.
    CalibrationStep 2
    Type the data value at each image edge. Values are prefilled from the data range as an approximate starting point — for accurate placement, replace them with the image's true bounds (see the test-data README for the demo values).
    Place 3 spread-out reference points on the image, then type each point's data coordinates. Handles rotation & skew.
    CSV coordinates are already image pixels (origin top-left, y down). No parameters needed.
    Edit positionsAfter calib
    Drag updates location columns live. Click map (with add mode on) places a new point. Click a point to view. Shift+click to edit. Alt+click to compare as slot B. Ctrl/Cmd+click to mark. Save to CSV keeps changes.
    EncodingsStep 3
    Low High
    Uncheck values to hide them from the map. Click legend items too.
    Filter by person without using speaker as color or shape — useful when one speaker has several stimulus images (e.g. I01 + I02).
    Display
    Fill shape keeps the base size & color; an independent open ring encodes the size variable — the two channels are visually de-linked.
    Grid lines are drawn in data space through the calibration — so Mercator shows its unequal latitude spacing, and affine calibrations show tilt.
    When several records share the same coordinates (e.g. municipality centroids), nudge them apart on the map. Visual only — saved CSV coordinates stay unchanged.
    Map navigation: scroll to zoom · drag the map to pan · +/− on the map corner · drag the ⋮⋮ grip to move those controls · ⌂ resets view.
    Export
    Save to CSV downloads the dataset with the current calibration embedded as a reserved __PLEWMAP_CALIB__ row. Export setup saves encodings, filters, calibration, and column roles as JSON (no image or audio).
