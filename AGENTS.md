# Instructions for AI coding agents

The instructions for this repository are in [`CLAUDE.md`](CLAUDE.md). They apply to every agent and tool, not only Claude.

The short version: after any change to `plew-map.html`, the layouts, the examples or the documents, follow the review procedure in [`tools/code-userguide-review.md`](tools/code-userguide-review.md), which runs `tools/checks/code-health.js` and `tools/checks/behaviour.js` and brings `CODE-MAP.md` and the user guide back in line with the code.
